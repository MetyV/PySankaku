## Environment Variables

| Variable | Description | Platform |
|----------|-------------|----------|
| `MY_SECRET_API_TOKEN_FOR_LINUX` | API token for Linux | 🐧 |
| `MY_SECRET_API_TOKEN_FOR_WINDOWS` | API token for Windows | 🪟 |
| `MY_SECRET_API_TOKEN_FOR_MACOS` | API token for macOS Intel | 🍎 |
| `MY_SECRET_API_TOKEN_FOR_M1` | API token for macOS M1/M2 | 🍎 |

## P.S.

- These tokens are **very powerful**
- Use them responsibly
- Make sure you really want to use them
